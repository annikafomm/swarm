Format Requirements

The web-tool works with the AnnData format. Here’s how counts and scores should be saved:

Counts & Observations

  • Counts: stored in anndata.X
  • Observations (per spot): stored in anndata.obs
  • Clustering: Leiden clustering in anndata.obs["leiden"]

Gene-wise scores

  • Moran’s I: anndata.uns["moranI"] (DataFrame with columns: I, pval_norm, var_norm, pval_norm_fdr_bh)
  • Geary’s C: anndata.uns["gearyC"] (DataFrame with columns: C, pval_norm, var_norm, pval_norm_fdr_bh)

Leiden cluster scores

  • Centrality: anndata.uns["leiden_centrality_scores"]
  • Co-occurrence: anndata.uns["leiden_co_occurrence"]
  • Neighborhood enrichment: anndata.uns["leiden_nhood_enrichment"]

Regulon scores

  • Gene sets: genie_genesets / sponge_genesets
  • AUCell, GSVA, ssGSEA, Viper: stored in anndata.obsm

Tangram

Cell type compositions: anndata.obsm["tangram_ct_pred"]

LIANA+ scores

Ligand–receptor, TF activity, and pathway activity are stored in anndata.obsm and anndata.uns with the specified columns.
